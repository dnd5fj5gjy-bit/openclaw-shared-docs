Partner Graphic Brief — Founder Testimonial Template

Reference storyboard + creative brief for building the partner poster set. Same system, reused for every white-label partner.

What we need

A set of graphics per partner, built from the reference storyboard below. Same layout, type hierarchy, icons and structure every time — only the partner's own logo, photo, name, quote and body copy change. Treat it as a template, not a bespoke design per partner.

Fixed vs. variable

Fixed — never changes

  • Layout, spacing and grid of each tile
  • Service icons: Blood Panels / Consultations / TRT / ED Support / Weight Loss
  • Trust badges: Clinician-led / Discreet & private / Science-backed / Results that matter
  • "Powered by Ted's Health" footer lockup
  • Colour system: black/white backgrounds, red accent, white/black text
  • Font system: bold condensed headline, clean body sans

Variable — swap per partner

  • Partner logo
  • Founder/owner photo
  • Founder name
  • Founder quote (1 line, personal reason for the partnership)
  • Body copy (2–3 lines: problem → solution → close)
