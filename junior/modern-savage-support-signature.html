3. How to install it

Easiest way, any mail client: select the signature block above with your mouse, from the thin line down to the last line, copy it, then paste it into the signature box in the mailbox settings. The formatting comes with it.

  1. Outlook on the web: Settings (gear) → Mail → Compose and reply → Email signature. Paste. Tick both "new messages" and "replies/forwards". Save.
  2. Outlook desktop: File → Options → Mail → Signatures. New, paste, set it as default for New messages and Replies/forwards.
  3. Gmail / Google Workspace: Settings (gear) → See all settings → General → Signature → Create new. Paste, then set the defaults underneath for both new mail and replies. Save Changes at the bottom of the page.
  4. Apple Mail: Mail → Settings → Signatures. Pick the support account, paste, and untick "Always match my default message font".

Choices worth knowing about

  • No logo image. Most mail clients block remote images by default and an inline one has to ride along as an attachment on every reply. A broken image icon on a customer support email looks worse than no image at all, so this is typography only. It is the same call we made on the Bear Grylls Ventures signature.
  • No personal name in the default version. It is a shared inbox, so the signature signs as the brand. The named variant is there for when someone wants to own a reply personally.
  • The three links are the three things customers write in about. Where is my order, when will it arrive, can I send it back. Every one is a live page on the site, checked today.
  • Colours are the site's own tokens - pine #0a140c, moss #525a50, blood orange #cc4a14, tallow #d4c89a - pulled from the modernsavage.co stylesheet, so it matches the shop rather than approximating it.
  • No phone number and no postal address, because neither is published on the site. If you want a returns address on it, send me the one Store and Ship will be using and I will add it.
